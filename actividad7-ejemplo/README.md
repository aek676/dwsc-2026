# Comandos para levantar cada proyecto

## Eureka Server

```bash
./mvnw spring-boot:run
```

## Compl

```bash
./mvnw spring-boot:run
```

## Sentence

```bash
./mvnw spring-boot:run
```

## Subject

```bash
./mvnw spring-boot:run
```

## Verb

- Default

```bash
./mvnw spring-boot:run
```

- Positive Verb

```bash
./mvnw spring-boot:run -Dspring-boot.run.profiles=positive-verb

```

- Negative Verb

```bash
./mvnw spring-boot:run -Dspring-boot.run.profiles=negative-verb
```
